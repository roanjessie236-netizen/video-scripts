# 样片 v3：真实素材为主＋AI 情景再现（2026-10-20）

v2 反馈后定的方向：**以真实素材为主**（历史照片、手稿、书刊、版画、实拍）；没有真实影像的段落用影视剧（电影《鲁迅》2005、《觉醒年代》，待片源）；少年时期用 AI 情景再现。全片 AI 约一成以内，集中在第一章。

## 规则
- **AI 画风 D：写实“情景再现”**——不露正脸（背影、侧影、手、物件、远景），少年留辫；画面右上角标“AI 情景再现”。影视剧镜头将来在角上标片名。
- **调色**：影视剧、AI、当代实拍统一“冷调旧胶片·中档”（降饱和、阴影冷调、抬黑压白；暗角 0.35 与颗粒逐帧叠加）。老照片、手稿、版画保持原样。
- **运镜**慢推/慢移；转场约 1 秒叠化；闪白＋震屏只用于“民族魂”、片名、铁锁、转身卡；史料首次出现时相片卡从下方飞入；浮尘很淡。镜头 4–8 秒。
- **统一介绍卡**（左上）：深色半透明底＋左侧红条，四行：类型（如“史料 · 照片”）／标题／时间·地点／出处；当代实拍用两行简卡（“今日 · 实拍”＋地点）。相片卡白边、-1.6° 左右倾斜、投影，背景为该照片的模糊压暗冷调版。
- **字幕**底部居中（思源宋体 44），原文下方加出处行“——鲁迅《……》”；亮画面下方自动加压暗渐变，纸面镜头改用墨色字。

## 文件
- `prep_v3.py`：AI 图去黑边、放大到 2400 宽并统一调色；当代实拍同样调色；史料生成 `card_*.jpg` 与模糊背景 `bg_*.jpg`；片名遮罩 `title_mask.png`。输出到 `src3/`（图片不入库）。AI 原图为会话生成文件，路径写在脚本里。
- `render_preview_v3.py`：`--plan` 打印字幕分句与镜头区间；`--stills 3,25` 输出静帧到 `/tmp/v3_*.jpg`；`--part k/n out.mp4` 分段渲染后 `ffmpeg -f concat -c copy` 拼接。总长 186.5 秒（正片 179.5＋片尾 7）。
- `v3/look.py`：调色强度对比与介绍卡样张（已确认“中档”）。
- 成片：`luxun90_preview_v3_S0-S1.mp4`（不入库）。
