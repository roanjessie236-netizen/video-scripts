# 创意方案｜《忘记我——鲁迅逝世九十周年》

## 一句话
1936年9月5日，鲁迅在《死》里写下遗嘱：“不要做任何关于纪念的事情。”“忘记我，管自己生活。”九十年后，我们拍一部“没有听他话”的纪念片——整部片子就是写给先生的一封回信。

## 1. 核心结构：一封回信
- **以遗嘱开场，以回信收尾。** 序章读《死》，尾声回到同一张稿纸，“忘记我”旁边慢慢写出“没有忘”。
- 旁白只在序与尾声用第二人称“先生”，正片用第三人称“他”，保持纪录片的克制。

## 2. 双声部
| 声部 | 内容 | 规则 |
|---|---|---|
| 【旁】今天的声音 | 交代史实、串联转折 | 语速约 4.2 字/秒；不煽情、不下结论式评价 |
| 【原】鲁迅的文字 | 只读鲁迅原文 | 93 条全部用《鲁迅全集》2005年版逐字核对；慢读约 3.3 字/秒；不做 AI 声音克隆 |

## 3. 按城市分章，以“六次转身”为线
| 章 | 城市/年份 | 转身 |
|---|---|---|
| 序 | 上海 1936 | 一份不让人纪念的遗嘱 |
| 一 | 绍兴 1881—1898 | 在当铺和药店的柜台前，看见了人心 |
| 二 | 南京·东京·仙台 1898—1909 | 一张幻灯片：放下手术刀，去医治人的精神 |
| 三 | 北京 1912—1922 | 铁屋子：沉默的抄碑人，发出第一声呐喊 |
| 四 | 北京 1923—1926 | 《过客》：看不见希望，也不向绝望下跪（反抗绝望） |
| 五 | 厦门·广州 1926—1927 | 思路轰毁：“青年必胜于老人”的信念碎了，却没有离开青年 |
| 六 | 上海 1927—1936 | 从进化论到“新兴的无产者”：找到新的信念，横站着护着青年往前走 |
| 尾声 | 上海 1936 | “无穷的远方，无数的人们，都和我有关。” |

## 4. 思想与事业主线（v2 新增）
v1 偏重生平与情感，v2 参考公众号文章《读懂毛主席才能真正读懂鲁迅》的思路，补强“他想了什么、做了什么”。所有新增内容都以鲁迅原文（全集逐字核对）或权威文献为据：

| 线索 | 镜头 | 依据 |
|---|---|---|
| 立人：一生事业的起点 | S2-09 | 《文化偏至论》“其首在立人，人立而后凡事举” |
| 国民性：写出国人的魂灵 | S3-06 | 《俄文译本〈阿Q正传〉序》 |
| 两种奴隶时代与“第三样时代” | S4-03 | 《灯下漫笔》 |
| 进化论 → 轰毁 → 救正 | S2-02 → S5-04 → S6-02 | 《〈三闲集〉序言》：创造社“挤”他读科学的文艺论，“救正”只信进化论的偏颇 |
| 左联：和实际斗争接触 | S6-04 | 《对于左翼作家联盟的意见》“左翼作家是很容易成为右翼作家的” |
| 立场：与“足踏在地上”的人站在一起 | S6-09 | 《〈二心集〉序言》“惟新兴的无产者才有将来”；《答托洛斯基派的信》（冯雪峰笔录、鲁迅审定） |
| 事业总览：小说、杂文、学术、翻译、编刊、木刻、扶植青年 | S6-11 | 《小品文的危机》“匕首”“投枪” |
| 最后的诗 | S7-01 | 《亥年残秋偶作》“起看星斗正阑干” |
| 身后评价 | S7-06 | 毛泽东《新民主主义论》（待 W33 核对原文） |

**没有采用的部分**：1966年书信等文革相关内容（偏离纪念主题，也有平台审核风险）；“鲁迅活着会怎样”之争；对周扬等人的定性（个人化论断，学界看法不一）；送火腿、转送方志敏文稿、“山大王气概”等回忆性轶事（列入 W37 待核，未核实不进片）；“说我不懂马克思主义……”一句（全集未检到）。另：文章说他4月29日辞职，全集年表为1927年4月21日；毛泽东原话是“主将”而非“总司令”。

## 5. 温度来自细节，而不是形容词
- 药店柜台和他一样高，当铺柜台比他高一倍；母亲筹来八元川资，“然而伊哭了”。
- 藤野先生用红笔改完他的讲义；照片背后的“惜别”。
- 《域外小说集》第一册卖出二十一本。
- 坐在坟的祭桌上拍照，“像一个皇帝”。
- “怜子如何不丈夫”。
- 柔石衣袋里的合同；《北斗》上那幅珂勒惠支的《牺牲》。
- 临终前两个月的夜里：“开开电灯，给我看来看去的看一下。”
- 绝笔便条：“十点钟的约会去不成了，很抱歉。”

## 6. 视觉语言
- **老照片为主**：林贤治《鲁迅画传》与《鲁迅全集》文前彩插（编号见 assets_index.md）。
- **木刻风动画补“没有照片的场景”**（当铺、幻灯片、铁屋子、过客、街灯之夜），向鲁迅倡导的新兴木刻致敬。
- **原文字卡**：仿宋/书宋，竖排或横排，黑底白字，留白多。
- **影视作品（v2.1）**：1936年丧仪纪录影像作为史料使用（W38）；传记片、电视剧和改编电影片段（W40、W41）只取画面、删除原声，角标注明片名与饰演者，避开说话口型特写，须获出品方授权。用在钱玄同夜谈、灯下写作、上海街头、瞿秋白、萧红等照片很少的场景，都在原镜头时长内替换或叠加。
- 色彩：童年段落唯一明亮；之后逐渐冷灰；尾声“街灯之夜”转暖。

## 7. 克制使用 AI
- 不做“老照片说话”、不做声音克隆、不让鲁迅“开口”；影视剧片段一律删除原声；目前没有找到可核验的鲁迅本人录音（W23），片中不宣称“鲁迅从未录音”，朗读者在片尾署名。
- AI 只用于木刻风插画/动画的辅助生成，片尾及平台按《人工智能生成合成内容标识办法》标识。

## 8. 一个母版，三种剪法
- **B站**：16:9 母版，19:31（20分钟以内），带章节时间戳。
- **抖音**：合集《鲁迅的六次转身》，E0 预告＋E1—E8（E7 为思想专集“他想要一个什么样的中国”），每集 1—2.5 分钟，前 3 秒钩子。
- **视频号**：约 5 分钟精华版，适合转发家庭群。
- 详见 cuts.md。

## 9. 真实性与版权红线
- 只引核对过的鲁迅原文；不使用网络伪名言（W27）。
- 何瓦琴“人生得一知己足矣”是鲁迅书赠瞿秋白，**不是鲁迅原创**。
- 上海十年曾领大学院特约撰述员薪俸，不写“不再领薪水”。
- 1930年代新兴木刻青年作者（黄新波、李桦、力群、曹白等）作品多在版权期内，不直接使用。
- 片中不写未核实的数字（送葬人数、故居时钟等），待 web_research_brief.md 中的核实任务完成。
