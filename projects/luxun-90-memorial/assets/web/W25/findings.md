# W25 核实记录

核验日期：2026-10-19；范围：第一轮 P0。

## 一句话结论

本轮没有查到三馆可直接适用于本片的公开图片商用许可；黄新波、李桦、力群、曹白个人木刻均不能仅因创作于1930年代就判公版。

## 已打开的可靠来源

1. [国家版权局：《中华人民共和国著作权法》](https://www.ncac.gov.cn/xxfb/flfg/flfg_532/202103/t20210309_50530.html)

   原文短摘录：“作者终生及其死亡后五十年”

   证据作用：第二十三条自然人作品的常规财产权期限；第二十条物权与著作权分开，第二十二条署名等人身权保护不受限制。以下日期为中国大陆通常个人作品规则的计算推论，不是个案授权意见。

2. [广东美术馆：黄新波作者简介](https://www.gdmoa.org/Exhibition/Exhibitions/2008/xgwd_2008/200810/t20081015_6853.shtml)

   原文短摘录：“黄新波（1916-1980）”

   证据作用：美术馆资料核作者卒年；不是版权代理证明。

3. [中国美术学院：新兴木刻先驱力群、彦涵作品选展](https://www.caa.edu.cn/info/1718/7471.htm)

   原文短摘录：“2012年2月10日”

   证据作用：艺术院校确认力群逝世纪年；不能据收藏者就认定现版权人。

4. [苏州革命博物馆：江南的呼吸——纪念江南社社长曹白](https://www.szgmbwg.org.cn/szgmbwg/hdjcg/202506/b334d036ccca4b409ea5743eee5cc09a.shtml)

   原文短摘录：“曹白（1914-2007）”

   证据作用：馆方2025.6.26研究文章确认生卒年；据此计算期限。

5. [蔡涛：鲁迅葬礼中的沙飞和司徒乔](https://www.chinawriter.com.cn/n1/2019/1212/c404063-31502649.html)

   原文短摘录：“李桦（1907-1994）”

   证据作用：学术文章图3的作者生卒年可核；本轮未取得李桦作品权利承继文件。

6. [北京市文物局：北京鲁迅博物馆](https://wwj.beijing.gov.cn/bjww/362771/362773/546583/index.html)

   证据作用：官方2025.9.17公布的是综合联系电话；需转文物图像复制或版权业务，不是已确认授权专线。

7. [上海文旅局：上海鲁迅纪念馆](https://whlyj.sh.gov.cn/zsdw/20151010/0022-30138.html)

   证据作用：官方2025.3.27公布综合电话，可询复制许可和高清图，不等于已授权。

## 可信度

高：法律条文、四位作者卒年、京沪官方综合电话；中：按常规个人作品规则计算期限；低：具体作品权利承继与三馆公开许可的完整性。

## 争议与证据边界

没有找到公开政策不等于馆方禁止一切使用，也不等于无需许可；馆藏物权、原作版权、照片复制服务和新摄影版权应分别核。匿名、合作、职务作品及其他法域不能机械套本表。
