# S6-11 修改与书影缺口

原旁白将“翻译了数百万字”放在“十八年里”统摄之下；已找到的约300万字是毕生译文全集口径，且包含早期文言翻译，不能用来证明仅十八年内的量。建议把“十八年里”与毕生事业总览分开，例如前一句讲写作，另句写“他一生译介的外国作品达数百万字，还编刊物、倡木刻、扶植青年”。不重核或改写后面的鲁迅原文。

| 所需书影 | 本轮结果 | 需要补的版本证据 |
|---|---|---|
| 中国小说史略 | 初版上下卷400×280组合图，C | 1923上卷、1924下卷分别高清 |
| 语丝 | ❌找不到合格高清原刊 | 刊次、年月、藏馆、母图许可 |
| 莽原 | ❌找不到合格高清原刊 | 同上 |
| 奔流 | ❌找不到合格高清原刊 | 同上 |
| 萌芽 | ❌找不到合格高清原刊 | 同上，避免同名晚出刊物 |
| 译文 | ❌找不到合格高清原刊 | 同上，避免晚出同名刊物 |
| 生死场 | 有馆方版本叙述；高清封面❌找不到 | 1935奴隶丛书初版原图 |
| 八月的乡村 | 有馆方文章；高清封面❌找不到 | 1935奴隶丛书初版原图 |

各缺口已试国家图书馆相关网络检索、中国现代文学馆公开出版物资料和作家网文章；缺失项未用现代再版封面填充。仍可对照用户本地既有书影，不能声称已替换某个HZ/QJ编号。
