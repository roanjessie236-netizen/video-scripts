# W03 送葬人数、地点、抬棺者：核实结果

## 一句话结论

日期与地点可以核实；“上万人”属于有出处的常见概数而非精确计数，完整抬棺名单尚不能确认，S0-05维持不写数字。

## 已打开的可靠来源与原文短摘录

1. [解放日报马信芳：90年前鲁迅先生逝世前后（中国作家网）](https://www.chinawriter.com.cn/n1/2026/1008/c404063-40810645.html)

   原文短摘录：“10月22日是安葬鲁迅的日子”

   证据作用与限度：结合前馆长张岚访谈，叙万国殡仪馆与万国公墓；和民进文章不是同稿转载。

2. [民主杂志李长青：一二·九运动中的民进前辈](https://www.mj.org.cn/zsjg/mzzzs/mzzxyd/wz/202001/t20200117_219044.htm)

   原文短摘录：“上海一万多人为鲁迅先生送葬”

   证据作用与限度：可靠机构的常见概数，不等于现场点名统计；京报另述出发6000余、沿途增至万人，统计对象须区分。

3. [上海党史网：为鲁迅抬棺的鹿地亘](https://www.ccphistory.org.cn/shds/shhm/content/c82cb8a1-1d73-4a89-b042-935f5bc9c96c.html)

   原文短摘录：“鹿地是抬棺者之一”

   证据作用与限度：只证此人，不替代全名单。

4. [京报网：鲁迅逝世90周年，葬仪却胜似国葬](https://news.bjd.com.cn/2026/10/19/12000336.shtml)

   原文短摘录：“鹿地亘、胡风、巴金、张天翼等十二个人”

   证据作用与限度：与常见16人说存在人数/环节口径差异，不据“等”补出名单。

## 可信度

高：安葬日期、两处地点及鹿地亘等部分参与者；中：上万量级；低：确切总数、完整抬棺名单。

## 争议与证据边界

“吊唁人次”“随行送葬者”“沿途送行者”不是同一统计对象。12人、16人等说法可能涉及不同环节或先后轮换，本次未取得当日全名单与清晰组照，不强行归一。只列可靠页面实际列出的鹿地亘、胡风、巴金、张天翼等，未补齐名字。
