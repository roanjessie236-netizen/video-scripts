# W33 核实记录

核验日期：2026-10-19；范围：第一轮 P0。

## 一句话结论

据《毛选》第二卷1991年第二版第698页，引文文字成立，但“媚骨”后原为逗号并续有下文，脚本截句须作省略处理。

## 已打开的可靠来源

1. [理论中国官方电子书：《毛泽东选集》第二卷，第698页](https://ebook.theorychina.org.cn/ebook/upload/storage/files/2022/07/26/ce338174299cae528b65e87a9ba78a5164510/files/basic-html/page370.html)

   原文短摘录：“没有丝毫的奴颜和媚骨，这是”

   证据作用：原书扫描已逐字核对非鲁迅文字；“中国文化革命的主将”同页可见；页图和版权页入库。

2. [国家新闻出版署：在纪念鲁迅诞辰140周年座谈会上的讲话](https://www.nppa.gov.cn/xxfb/ywxx/202109/t20210929_664342.html)

   原文短摘录：“这是殖民地半殖民地人民最可宝贵的性格”

   证据作用：2021年正式讲话独立转引完整句，交叉核“媚骨”后的逗号和续文；定本仍以《毛选》原页为准。

3. [共产党员网：1940，“我们要建立一个新中国”](https://www.12371.cn/2021/04/17/ARTI1618621323773378.shtml)

   原文短摘录：“《中国文化》”

   证据作用：提供创刊号／单行本低清组合图及初刊叙述；没有原刊高清逐页扫描。

4. [上海党史网／《党史镜报》顿文聪：85年前，上海文化界如何宣传阐释毛泽东的《新民主主义论》](https://www.ccphistory.org.cn/shds/dsxx/content/45b7198e-b66e-4145-8a74-f6aa48828d0c.html)

   原文短摘录：“延宕至3月下旬”

   证据作用：2025年研究区分《中国文化》标定刊期与实际印出时间，认为《解放》周刊1940.2.20先发表。与通行2.15初刊说有差别，不能掩去。
