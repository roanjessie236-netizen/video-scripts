# S7-06 改动建议（未直接改写脚本）

脚本原说法：毛泽东称他是“中国文化革命的主将”，写道：“鲁迅的骨头是最硬的，他没有丝毫的奴颜和媚骨。”

发现：[《毛泽东选集》第二卷第698页](https://ebook.theorychina.org.cn/ebook/upload/storage/files/2022/07/26/ce338174299cae528b65e87a9ba78a5164510/files/basic-html/page370.html)在“媚骨”后使用逗号，续谈殖民地半殖民地人民的性格。现脚本用了原文没有的句号。

建议：旁白保留现有节引长度时，字幕写“鲁迅的骨头是最硬的，他没有丝毫的奴颜和媚骨……”并注明节引及出处；或者完整显示原页该句。若重新排字幕以完整引文为准，需给后半句留够阅读时间。

画面标注具体版本：定本文字核对用“《毛泽东选集》第二卷，人民出版社1991年第二版，第698页”；历史书影用“1940年《中国文化》创刊号”并说明组合图中另有单行本。不要把1991年页图标成1940年初刊。
