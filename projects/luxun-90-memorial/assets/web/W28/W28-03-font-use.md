# 字体实施方案

片名：《忘记我》用霞鹜文楷Regular；正文用朱雀仿宋。二者均为OFL 1.1，分级B。先在实际剪辑软件检查缺字及字重，不使用来源不明的“鲁迅字体包”。

- [霞鹜文楷官方仓库](https://github.com/lxgw/LxgwWenKai)；[Regular原始TTF](https://raw.githubusercontent.com/lxgw/LxgwWenKai/main/fonts/TTF/LXGWWenKai-Regular.ttf)。文件超过任务书上限，不随本包上传。
- [朱雀仿宋官方仓库](https://github.com/TrionesType/zhuque)。从作者提供的正式发行入口取得字体。
- 随工程交付字体时同时附本目录两份许可证；不要单独售卖字体，不擅改保留名称。
- 若决定用方正鲁迅行书，先购买覆盖视频、三平台及相应商业用途的许可，保留订单与合同；当前C。
