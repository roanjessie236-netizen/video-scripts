# 鲁迅题材木刻作品（W42）

用户提供的画作包《【主题】鲁迅》共63张，入选 **36张**（正片候选16张、备用20张），不建议使用27张。完整信息见 `index.csv`。

## 结论
- **入选的全是木刻**：黄新波《鲁迅诗意》、赵延年鲁迅小说插图、古元、冒怀苏、汪刃锋、曾景初、戈沙、张嵩祖、顾炳鑫。黑白木刻正是鲁迅倡导的新兴木刻语言，和全片视觉一致，**可代替部分AI木刻风画面**。
- **全部在著作权保护期内**（美术作品保护到作者去世后第50年年底，例如黄新波1980年去世，保护到2030年底），状态 C：**须获作者或继承人授权，未获授权不进成片**。

## 使用规则
1. 裁掉画册扫描中的图注、页码，角标署“作者·《作品名》（年份）”。
2. 只做推、拉、摇；**不得AI改画、临摹、上色，也不让画“动起来”**。
3. 片尾字幕加“木刻作品作者与授权”。
4. 年份、出处标“待核”的，W42 落实后再写进角标。
