# 配音（试听阶段）

- `timeline.py`：从各章渲染脚本导出字幕时间线（起点、类型、全文）。
- `tts.py`：edge-tts 逐句合成，按字幕窗口迭代调语速；EMO 重点句放慢降调；PRON 读音替换（只改配音稿）；旁白/原文分别处理（原文放慢、降调、轻混响）。
- `sample.py`：试听段（序 0—68 s＋尾声 S7-05—S7-07）两版混音：J＝旁白云健＋原文云扬，Y＝旁白云扬＋原文云健；配乐《觉醒年代》原声（序一段静的音乐，尾声《期盼》），人声时压低 11 dB；成品两遍 loudnorm 到 -16 LUFS / -1.5 dBTP。
- 依赖：`pip3 install --target /tmp/pylib edge-tts`；配乐取自 B站 BV1kf4y1a7Hm（jx1/jx2.m4s，不入库）。
