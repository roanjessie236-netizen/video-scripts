# 配音（试听阶段）

- `timeline.py`：从各章渲染脚本导出字幕时间线（起点、类型、全文）。
- `tts.py`：edge-tts 逐句合成，按字幕窗口迭代调语速；EMO 重点句放慢降调；PRON 读音替换（只改配音稿）；原文声音方案由 `QPROF`（语速/音高、滤镜、合成房间混响）切换；原文不读快（最快 -4%），可延到下一句前 0.5 秒。缓存键用 md5。
- `sample.py`：第一轮试听（J＝旁白云健＋原文云扬，Y＝对调）。**结论：旁白定云健（A）**；原文云扬被否。
- `sample2.py`：第二轮，原文三候选——C1 云希·自然（-14%/-4Hz，RT60 0.6 s 湿声 -15 dB）；C2 云希·旧录音（-16%/-7Hz，200–5200 Hz＋1.8k 提升＋软削波）；C3 云健·旧录音（-16%/-4Hz）。另出四句长段原文对比（Q17/Q28/Q31/Q40，无配乐）。zh-TW-YunJheNeural 目前合成中文报 NoAudioReceived，未用。
- `ln.py`：两遍 loudnorm（-16 LUFS / -1.5 dBTP，linear）。
- 配乐《觉醒年代》原声（B站 BV1kf4y1a7Hm，jx1/jx2.m4s，不入库）：序一段静的音乐，尾声《期盼》，人声时压低 11 dB。
- 依赖：`pip3 install --target /tmp/pylib edge-tts`。
- 交付：Notion 分镜页下“配音试听｜旁白音色二选一”“配音试听 第二轮｜原文声音三选一”。
