# 简史三部曲 · 封面与发布文案

- `make_covers.py`：封面生成脚本。横版直接取每部片子开头的标题帧（2560×1440 和 1920×1080）；竖版取片中的关键画面做 9:16 居中裁切，压暗处理后重新排版标题（1080×1920），另外导出 3:4 居中裁切（1080×1440）。
- 取帧时间：①人类简史 标题帧 19.0s / 竖版背景 17.0s；②未来简史 25.0s / 28.0s；③今日简史 21.6s / 18.2s。
- 字体：Noto Serif CJK SC（Black / Bold / SemiBold / Regular）。
- 竖版安全区：所有文字都在 3:4 居中裁切范围内，钩子文案放在 y=1400，避开抖音底部的界面遮挡。
- 发布文案：见 `publish_copy.md`。
