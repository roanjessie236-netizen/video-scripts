# 补单（缺失 / 返修素材）

## 规则

- 剪辑端每收到一批素材，按 `asset_requirements.md` 逐条验收；未交付或不合格的镜头写入下表，**编号不变**
- 返修文件命名 `S0xx_r1.jpg`，再次返修为 `_r2`；剪辑始终使用最新版本
- 补单处理完成后，把 `asset_status.csv` 中对应镜头改为“已通过”，补单次数加 1
- 补单期间剪辑不停工：缺失镜头先用同段落相邻镜头延长或黑场占位，时间码不变，素材到位后直接替换

## 原因代码

| 代码 | 含义 |
|---|---|
| M | 缺失（未交付） |
| R | 分辨率不足或画幅不是 16:9 |
| T | 画面含文字、伪文字、Logo、水印 |
| S | 字幕留白区（A / B / C）不干净 |
| C | 固定角色外观不一致 |
| D | 手指、面部、结构畸形 |
| L | 授权或来源不清 |
| V | 内容或色调与需求不符 |
