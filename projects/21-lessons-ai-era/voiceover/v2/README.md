## v2.1：重配第 5 句「思考」

- 问题：「思考。」两个字单独合成时，“思”的 s 擦音拖长、“考”压到约 90 Hz、偏沙哑，听感和发音都怪；Whisper small 把它识别成「复刻」。
- 做法：参数不变（−8% / −2 Hz / +3%），改为一次合成「更深层的东西——思考。」，在破折号停顿最安静处（−74 dB）切出「思考」（`lines.json` 的 `ctx` 字段，`tts_line.py` 自动处理）。“思”的元音回到正常音区（约 130 Hz），Whisper 识别为「思考」（思 0.98 / 考 1.00），时长 0.65 → 0.56 s。
- 其余不变：`replace_l5.py` 只把 15.4–18.5 s 换成新混音（50 ms 交叉淡化）；画面流与 v2 逐字节相同，其他音频与 v2 的差值约 −52 dB（只是重新编码 AAC 的量化噪声）；−14.1 LUFS · LRA 5.6 LU · 真峰值 −0.9 dBTP，与 v2 相同。

## 因中文字幕已烧录而做的适配

- **6 组半句合为一句合成**（保持一句话的连贯语调）：8+9、10+11、12+13、14+15、17+18、33+34 → 41 条字幕共 35 段旁白 + 2 句片尾字幕。
- **合并句后半句对齐**：在同一次合成内把逗号停顿拉长（`pause_fit.py`，与《人类简史》v3.2 收紧停顿同法、方向相反），后半句正好在它的烧录字幕出现 0.15 s 后开口：
  #8 0.24→0.80 s · #10 0.24→1.14 s · #12 0.20→1.25 s · #17 0.24→0.97 s · #33 0.29→1.14 s（#14 本来就对齐，误差 −0.07 s，未改）。
- **#4、#27** 比字幕槽位略长：语速取 −4 %，并分别提前 0.10 s / 0.20 s 开口，结尾与字幕消失同步（+0.05 s）。
- 其余句子全部在烧录字幕结束前说完；句间间隔 ≥ 0.9 s；分词检查无「想成 / 为什么」类断句问题（句内最长无标点停顿 0.12 s）。

| `mix_report.md` | 混音报告（逐句明细） |
