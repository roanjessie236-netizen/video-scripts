# 今日简史：AI时代，人类如何重新定义自己（2K 未来纪录短片 · 筹备中）

- 规格：2560×1440 · 16:9 · 24fps · 约 3:43（223.0s）· 56 个镜头（S001–S056）· 43 条字幕
- 结构：开场「文明转折」→ 第一章「智能的诞生」→ 第二章「工作的重新定义」→ 第三章「创造力属于谁？」→ 第四章「AI时代的人类答案」
- 灵感来自尤瓦尔·赫拉利《今日简史》中关于就业、终身学习与认识自我的讨论；“无用阶级”作为风险呈现，未来科技场景作为想象呈现
- 视觉：《流浪地球》的文明尺度 + 《星际穿越》的宇宙哲学感 + BBC 纪录片的真实质感；冷灰、深蓝逐渐转向金色、暖白与宇宙蓝；人物与宏大空间交替推进

## 分工与流程

1. **剪辑端（Notion AI）**：脚本、分镜、素材需求表、字幕（本目录）
2. **素材端（GPT）**：按 `gpt_brief.md` 生成图片、搜集网络素材，按镜头编号交付
3. **剪辑端**：逐条验收 → 缺失或不合格的镜头写入 `reorder.md` 补单（保留原编号）→ 剪辑、调色、字幕、配乐 → 导出 `out/21_lessons_ai_era_2K.mp4`
4. 每轮验收结果同步到 `asset_status.csv`

镜头编号 S001–S056 固定不变。素材文件名与编号一致（如 `S012.jpg`），剪辑按编号直接套用；返修版本用 `_r1`、`_r2` 后缀。

## 文件

| 文件 | 作用 |
|---|---|
| `asset_requirements.md` | **素材需求表 / 总脚本**：56 个镜头的时间码、时长、旁白字幕、画面描述、画幅、素材类型、生成提示词、搜索关键词、字幕留白 |
| `narration.srt` | 字幕文件（43 条，与需求表时间码一致） |
| `asset_status.csv` | 素材状态跟踪（待交付 / 已交付 / 需补单 / 已通过） |
| `reorder.md` | 补单：缺失与返修素材清单 |
| `gpt_brief.md` | 素材端任务书，可直接复制给 GPT |

剪辑工程（timeline.py、配乐、渲染脚本）会在素材到位后加入本目录，沿用 `../homo-deus-future` 的渲染引擎。
