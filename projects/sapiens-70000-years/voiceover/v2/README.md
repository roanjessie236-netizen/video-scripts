# 《人类简史》v2 旁白配音

- 音色：edge-tts `zh-CN-YunjianNeural`（与《今日简史》一致），38 句旁白 + 2 句结尾字幕
- 每句**一次合成**（不拼接），停顿交给标点，语气连贯；基础语速 −5%，按情绪在 −4%~−8% 之间微调，结尾两句 −15% 放慢
- 实测语速 3.6–5.0 字/秒，句间间隔 ≥ 0.6 s；所有句子都在自己的时间槽内，无需自动加速
- 字幕起点 = 旁白起点 − 0.15 s，终点 = 旁白结束 + 0.5 s（不压下一句）

| 文件 | 作用 |
|---|---|
| `lines.json` | 台词、英文、旁白起点 `s`、语速 / 音高 / 音量、情绪提示 `cue` |
| `tts_line.py` | 合成每句 → `clips/NN.wav`、`durs.json`、`fit.json` |
| `durs.json` / `fit.json` | 本次合成的实测时长与参数 |
| `vo_starts.srt` | 旁白起点（混音对齐用） |
| `mix_tl.py` | 人声链路 + 配乐闪避 + 人声优先补偿 + −14 LUFS 母带（沿用《今日简史》） |
| `run_v2.sh` | 一键出片（需 `assets/` 素材） |

混音参数：配乐 −5 dB，侧链闪避 3:1，人声至少高出配乐 12 dB（不足时最多再压 7 dB），成片 −14 LUFS / 真峰值 ≤ −1 dBTP。
