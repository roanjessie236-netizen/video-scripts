# v3 · 节奏调整版（Sapiens 70000 年）

在 v2 成片（`../v2_from_film/`，284.1 s）的基础上做两件事：

1. **第 37 句旁白重写**
   - 旧：「真正的问题不是我们想成为什么，而是——我们想要“想要”什么？」（EN: *…but what we want to want.*）
   - 新：**「真正的问题，不是我们想成为什么，而是——我们究竟应该想要什么？」**
     EN: *The real question is not what we want to become, but what we should want.*
   - 重新合成：edge-tts 云健（zh-CN-YunjianNeural），rate −5%、pitch +0 Hz、volume +3%（与原 37 句同参数），
     时长 5.92 s，响度 −23.4 LUFS（与旧版一致），在「问题 / 成为 / 什么 / 而是——」后保留停顿。
   - **v3.1 断句修正**：原文直接送 TTS 时，引擎把「想成为什么」切成「想成 / 为什么」（WordBoundary 实测：`想成[2.01–2.44] 为什么[2.46–2.97]`）。
     朗读文本改为「不是我们想成为␣什么」（`lines.json` 中 `t` 为朗读文本，`sub` 为字幕文本，字幕不变），
     切分变为 `想[1.96–2.15] 成为[2.17–2.59] 什么[2.77–3.13]`，「成为」后约 0.19 s 小停顿；仍是一次合成、不拼接，后加 +0.4 dB 对齐响度。
     对比测试：加引号「“成为”什么」也能断对但没有停顿；逗号 / 顿号 / 破折号与空格效果相同。
     画面与配乐不变：新旧成片除 270–277 s 外音频逐样本一致（差值 −120 dB）。
2. **按音乐段落重新分配节奏**：旁白密集的章节放慢，留白过多的段落收紧；用户自己剪的片尾原样保留，只整体平移。

## 方法

- **画面**（`render_v3.py`）：输出帧 j → Winv(j/24) → 最近的 v1 源帧；放慢的段落里同一源帧会重复，
  因此对每个镜头的主运动（推拉摇移，不含抖动）按新时间重新投影：D = A(t)·A(m/24)⁻¹，INTER_CUBIC + BORDER_REFLECT，
  保证运动连续（实测地图镜头 3.3–3.7 px/帧，平稳，无顿挫）。
  文字层（地名标签、跑马灯、章节卡、片名、字幕、片尾卡）不参与变形，用精确 alpha 从源中贴回，保持锐利；
  v2 字幕先从源帧中清除，再在新时间重新排版。片尾直接用用户成片帧（偏移 593 帧）。
  自带低内存编码器：x264 CRF 18，2 线程，分 16 段（480 帧 / 段）并行渲染后无损拼接。
- **配乐**（`mk_music_v3.py` → `music_v3.py`）：不是拉伸音频，而是在音符层面重排：每个音符 / 打击 / 铺底 /
  合唱 / 铜管 / 上升音效的起点用 W 映射，持续音按 f 伸缩，长笛节拍按 f 调整，打击重音全部落在变速后的画面切点上。
- **字幕 / 时间轴**（`timeline_v3.py`）：生成 `shotlist_v3.json`、`vo/vo_starts_v3.srt`、`vo/fit.json`
  以及双语 / 中文字幕 `audio/sapiens_v3_2K_subtitles_*.srt`。
- **混音**：`../voiceover/v2/mix_tl.py`（与 v2 相同参数：音乐 −5 dB、侧链闪避 3:1、人声 −16 LUFS、整体 −14 LUFS）。

## 路径说明

脚本保留了制作时的沙盒绝对路径：`/data/v2f` = `../v2_from_film`，`/data/sp/vo2` = `../voiceover/v2`，`/data/v3` = 本目录。
