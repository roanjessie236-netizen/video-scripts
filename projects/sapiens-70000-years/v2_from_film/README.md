# v2_from_film — 用成片重建 v2 2K 画面（无需原始素材）

《人类简史》v2 的最终交付：**2560×1440 · 24 fps · H.264 High（CRF 18）· 28.7 Mbps · 284.125 s · 1.03 GB**，旁白 = v2 生成旁白（Yunjian，40 句），配乐 = 按用户剪辑的结尾重新对位的 v2 配乐。

## 为什么要这样做

- 仓库（全部提交历史、两个仓库）里都没有图片素材（`assets/NN_name.jpg`、`parchment.jpg` 从未提交），无法按 `run_v2.sh` 从头渲染。
- 上一版预览 `sapiens_v2_vo_preview.mp4` 只有 1280×720、视频码率约 23 kbps，所以很糊。
- 唯一可用的高清画面是用户上传的整片《人类简史》.mp4（HEVC 2560×1440 · 30 fps · 284.134 s · 约 20.7 Mbps）。
  它就是 v1 渲染经剪辑软件导出的结果：用户帧 k 显示 v1 帧 floor(0.8k)（k ≤ 7991，t < 266.4 s）；
  之后是用户自己剪的结尾（站点→孩子的叠化 7992–8001、孩子镜头、8349 硬切到结尾镜头、片尾卡、淡出）。

## 方法

1. **帧映射**（`core.k_of_j`）：输出 24 fps、6819 帧（284.125 s）。j ≤ 6392 → k = ceil(1.25·j)（与 v1 帧一一对应，无重复/丢帧）；
   j ≥ 6393 → k = 7992 + round((j − 6393)·1.25)（保留用户的结尾剪辑）。
2. **精确的 v1 模型**（`v1core/` = 仓库渲染代码 + v1 shotlist）：字幕层位置、镜头运动矩阵、post（增益/闪白/暗角/各种 scrim 的量化值）、
   星空/余烬叠加、闪烁、颗粒图案。核对结果：旧字幕位置逐像素吻合；v1 的 8 张颗粒图在两次有损编码后仍以 10–35% 存在，
   逐帧最小二乘拟合（`core.fit_grain`）。
3. **第 1 遍：干净背景板**（`build_plates.py`）：对每个有旧字幕的镜头，把所有用户帧通过 v1 管线逆运算
   （去字幕 alpha/预乘色、去 post、去叠加特效）并按相机矩阵反投影回素材坐标，只累积“字幕+光晕”以外的可信像素，
   得到 31 张素材空间背景板（`plates/plan.json`），空洞用 push-pull 补齐。
4. **第 2 遍：去除旧字幕**（`fill.clean_band`）：字幕区域 = 直接反演像素（字幕较透明处）与“背景板 → 相机 → 转场 → v1 post”
   重新渲染的像素按字幕不透明度混合；用可信像素做低频比率校正（σ10/σ40），再补回拟合出的颗粒。2× 增益下也基本看不出痕迹。
5. **v2 双语字幕**（`render_v2f.py`）：把 v1 的字幕底部 scrim 换成 v2 的（逐行比值），按 v2 `render.py` 完全相同的
   字体/位置/淡入淡出画上中文 + 英文字幕（38 句），并在字形下补回颗粒。
6. **结尾**：用户结尾里烘焙的中文问句与 v2 中文完全一致，保留不动；测得其逐帧不透明度（`cap_alpha.py` → `cap_alpha.json`，
   归一化 (a − 0.05)/0.93、3 帧平滑），按同样的不透明度叠加 v2 英文行（Where do we come from? / Where are we going?）。
7. **清晰度**：全帧轻度亮度锐化（unsharp σ 2.0、0.35，在画新字幕之前，字幕本身保持锐利），x264 High CRF 18，BT.709 tv range 标记。
8. **配乐**（`music_v2f.py`）：v2 配乐，时长 284.125 s；落点 266.3 s（对齐用户的叠化）；合唱 266.3 / 275.6 / 278.3 s，
   独唱旋律 267.0 s 起（时值 ×0.9，最后一个音 278.25 s 对齐硬切）；FFT 长度取 7-smooth（12 544 000 样本），避免内存溢出。
9. **旁白**：同一套 40 句 TTS 片段与参数（`--music-db -5 --duck-thr 0.05 --duck-ratio 3 --voice-lufs -16 --target-lufs -14 --min-vmr 12 --max-ride 7`）；
   1–38 句起点不变，39 句 271.40 s、40 句 275.85 s（对齐用户结尾里两句问句的淡入），见 `audio/vo_starts_v2f.srt`。

## 文件

| 文件 | 作用 |
|---|---|
| `core.py` | v1 模型：帧映射、字幕层、post 参数、相机、叠加特效、颗粒拟合、顺序解码 |
| `overlays.py` | 标签/年代条/章节卡/标题/片尾卡/问句/路线图的遮罩（背景板累积时排除） |
| `build_plates.py` | 第 1 遍：素材空间背景板 → `plates/*.npz`（二进制，未上传）+ `plates/plan.json` |
| `fill.py` | 第 2 遍：字幕区域重建（背景板渲染 + 反演 + 比率校正 + 颗粒） |
| `render_v2f.py` | 主渲染：15 段 × 480 帧，可断点续跑（`segs/seg_XX.mp4`） |
| `cap_alpha.py` / `cap_alpha.json` | 结尾问句的逐帧不透明度测量 |
| `music_v2f.py` | 按新结尾对位的配乐 |
| `audio/vo_starts_v2f.srt` | 旁白起点（新结尾） |
| `audio/sapiens_v2_2K_report.md` / `.srt` | 混音报告、旁白时间轴字幕 |
| `grab.py`, `test_clean.py`, `crop11.py`, `diag1.py`, `chk1.py`, `chk2.py` | 取帧与检查脚本 |
| `v1core/` | v1 模型所用的渲染代码与 v1 shotlist / timeline |
| `run_v2f.sh` | 一键复现（需要用户整片作为输入） |

## 成片实测

- 视频：2560×1440 · 24 fps · 6819 帧 · H.264 High · 28.7 Mbps；音频 AAC 256 kbps / 48 kHz
- 响度：−14.1 LUFS · 真峰值 −1.0 dBTP；人声高出配乐中位 12.0 dB（最小 11.5 dB）
- 渲染耗时：第 1 遍背景板约 5.5 分钟，第 2 遍 15 段约 47 分钟（2 核 CPU）
- 另附 `audio/sapiens_v2_2K_subtitles_bilingual.srt`（中英双语外挂字幕，含结尾两句问句）
