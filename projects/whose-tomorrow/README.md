# 明天属于谁？· WHOSE TOMORROW?

**从磨坊到算法 · 简史三部曲终章** — 约 4 分 25 秒（v3，265.1 s）的 16:9 解说短片，2K（2560×1440，24 fps）。
从凯恩斯 1930 年“每周工作 15 小时”的预言出发，用历史唯物主义的“生产力—生产关系”框架，
把赫拉利三部曲（《人类简史》《未来简史》《今日简史》）的线索串起来，追问：
**当机器能生产一切，财富该属于谁？** 结论：技术决定可能性，制度决定结果；
共同所有、共同分享的明天，要靠人们共同争取。

备选片名：《丰裕之后》《从磨坊到算法》。

## 制作方法

- **旁白**：`voiceover/lines_wt.py` → `voiceover/lines.json` → edge-tts（zh-CN-YunjianNeural），49 句；中英双语字幕（`subtitles/`）。
- **画面**：AI 生成插画（提示词见 `tools/prompts.py`；`tools/gen_horde.py` / `tools/horde.py` 调用 AI Horde），
  超分到 2K 并统一调色；自绘图表（`tools/diagrams.py`）。
- **时间线**：`timeline_wt.py` → `engine/shotlist.json`（79 个镜头、4 个章节卡、14 条出处标注、7 张引言卡）。
- **渲染引擎**：`engine/render.py` + `engine/render_core.py` + `engine/fx2.py`（v2 起为完整引擎文件，不再需要打补丁）。
- **配乐**：`tools/score_wt.py` 程序化合成，`tools/build_music_wt.py` 生成 `music_wt.py`。
- **混音**：响度 −14 LUFS，真峰值约 −1.4 dBTP，旁白高于音乐约 14 dB。
- **渲染**：`seg_render_wt.sh` 按帧精确分 11 段渲染，再拼接并混入音轨，输出 2K。

## 文件

- `timeline_wt.py`、`seg_render_wt.sh`、`setup.sh`

- `tools/`：图像生成与检查、深度图、图表、配乐、字幕导出
- `voiceover/`：旁白脚本与参数
- `subtitles/`：中英双语 / 中文 / 英文 SRT
