# 明天属于谁？· WHOSE TOMORROW?

**从磨坊到算法 · 简史三部曲终章** — 约 4 分钟（4:09）的 16:9 解说短片。
从凯恩斯 1930 年“每周工作 15 小时”的预言出发，用历史唯物主义的“生产力—生产关系”框架，
把赫拉利三部曲（《人类简史》《未来简史》《今日简史》）的线索串起来，追问：
**当机器能生产一切，财富该属于谁？** 结论：技术决定可能性，制度决定结果；
共同所有、共同分享的明天，要靠人们共同争取。

备选片名：《丰裕之后》《从磨坊到算法》。

## 制作方法

- **旁白**：`voiceover/lines_wt.py` → edge-tts（zh-CN-YunjianNeural），47 句，约 198 秒；中英双语字幕。
- **画面**：AI 生成插画（Z-Image-Turbo，经 AI Horde 生成，提示词见 `tools/prompts.py`），
  经超分到 2944×1656 并统一调色；部分复用《未来简史》片的插画与自绘图表（`tools/diagrams.py`）。
  个别画面里 AI 生成的乱码文字做了手工修补（`tools/patch_wt.py`）。
- **时间线**：`timeline_wt.py` → `engine/shotlist.json`（57 个镜头，4 个章节卡，15 条出处标注）。
- **配乐**：`tools/score_wt.py` 程序化合成（雨声+钢琴 → 工业锤击 → 电子 → 洪水/都江堰 → 温暖转折 → 进行曲与合唱收束）。
- **混音**：响度 −14 LUFS，真峰值 ≤ −1 dBTP，旁白高于音乐约 12–14 dB。
- **渲染**：`seg_render_wt.sh` 按帧精确分段渲染并合成 2K（2560×1440，24 fps）。

## 文件

- `timeline_wt.py`、`seg_render_wt.sh`、`setup.sh`

- `voiceover/`：旁白脚本与时间
- `engine/tools/patch_engine.py`：对共用渲染引擎的补丁
